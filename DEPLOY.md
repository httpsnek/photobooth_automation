# InstaBOX — установка на точку

Порядок важен: пароль API берётся из dslrBooth, поэтому dslrBooth настраивается
**до** заполнения `.env`. Поштучный чек-лист с отметками — `DEPLOY_CHECKLIST.md`.

---

## 0. Под рукой

- Ноутбук будки на Windows 10/11; камера и принтер уже работают в самом dslrBooth.
- Сенсорный монитор: **HDMI** (картинка) + **USB** (касание) в ноутбук.
- Интернет для оплаты (свой роутер, не гостевой Wi-Fi ТЦ).
- Python 3.10+ с python.org — при установке **отметить «Add python.exe to PATH»**.
- Google Chrome (если нет — подхватится Edge).
- Владелец нажал **Start** у бота `t.me/InstaBOX_control_bot`.

## 1. dslrBooth

1. Войти в аккаунт с подпиской.
2. Сессия **Print** на 4 кадра; автопечать без подтверждения.
3. Экраны шеринга (email / SMS / QR-share) — **выключить**, иначе dslrBooth зависает на них.
4. *Screen Editor → Capture Screen* → **Show Live View** — включить.
   *Capture Settings → Photo* → «Time Before First / Other Photos» **больше 3 с**.
5. Просмотр каждого кадра с кнопкой **Retake**, ~5 с.
6. **«Always on top» — выключить**, иначе наш экран с QR никогда не окажется сверху.
7. *Settings → General → API* — включить, **скопировать пароль**.
8. *Settings → General → Triggers* → URL: `http://127.0.0.1:8000/dslrbooth/event`
   (именно `127.0.0.1`; токен для этого ПК не нужен).
9. Ярлык dslrBooth — в `shell:startup`.

## 2. Установка

Распаковать архив → правой кнопкой **`СТАРТ_ТУТ.bat` → Запуск от имени администратора**.

1. Откроется `.env` в Блокноте. Заполнить строки с `<<< ЗАПОВНИТИ`
   (`BANK_TOKEN`, `DSLRBOOTH_API_PASSWORD`, `SUPPORT_TELEGRAM`, `PAPER_CAPACITY`)
   и, очень желательно, Telegram-бота. Ctrl+S, закрыть Блокнот.
2. Дальше всё само: Python и зависимости, задачи автозапуска, правило брандмауэра,
   питание (сон, USB-suspend, **крышка = ничего не делать**), генерация `ADMIN_TOKEN`.
3. В конце — **самопроверка** и список адресов. `[ FAIL ]` → исправить `.env`
   и запустить `СТАРТ_ТУТ.bat` ещё раз: каждый запуск останавливает старый
   бэкенд и применяет текущий `.env`.

Если Python не найден или нет интернета, установщик остановится и скажет об этом красным.

## 3. Windows (вручную)

- **Автовход** (`netplwiz` → снять «Требовать ввод имени пользователя и пароля»).
  Без него после перезагрузки ничего не запустится.
- Устанавливать под **той же** учётной записью, под которой будка входит автоматически.
- Закрыть крышку ноутбука — монитор станет единственным экраном.
- Калибровка касания: «Параметры планшетного ПК» → *Настроить*.
- Windows Update — часы активности на весь день.

## 4. Проверка без денег

С телефона в той же сети откройте адрес **Window test** из итогов установки:
`http://<IP>:8000/admin/test-windows?token=<ADMIN_TOKEN>` — на экране будки
вынырнет dslrBooth и через 4 с вернётся наш экран; телефон покажет, что нашлось.

## 5. Боевой тест (1 грн)

1. В `.env`: `PRICE_UAH=1`, запустить `СТАРТ_ТУТ.bat` ещё раз.
2. Оплатить 1 грн: dslrBooth выныривает (видно себя) → отсчёт → кадры → Retake →
   печать → наш экран возвращается сам: «Друкуємо» → «Готово» → новый QR.
3. Проверить возврат: закрыть dslrBooth, оплатить ещё 1 грн → деньги вернутся, в Telegram ⚠️.
4. `PRICE_UAH=150`, ещё раз `СТАРТ_ТУТ.bat`.

## 6. Всё поднимается само

Выключить питание ПК на 10 с → включить → Windows вошёл сам → бэкенд, dslrBooth и
киоск поднялись → `check.bat` снова без `[ FAIL ]`.

## Если что-то не так

| Симптом | Куда смотреть |
|---|---|
| Экран «Тимчасово не працює» | причина — в Telegram и на `http://<IP>:8000/status` (строка «Блокування», все причины списком) |
| Правки в `.env` не применились | запустить `СТАРТ_ТУТ.bat` ещё раз — он перезапускает всё |
| Камера не снимает по оплате | `check.bat` → строка `dslrbooth`; неверный `DSLRBOOTH_API_PASSWORD` назван прямо в причине |
| После двух сбоев подряд точка не продаёт | так и задумано: блокировка, чтобы не брать деньги впустую. Исправить причину → `…/admin/resume?token=…` (или само через 15 мин) |
| dslrBooth не выныривает / наш экран не возвращается | `…/admin/test-windows?token=…`; в dslrBooth выключено «always on top»? |
| Нет событий от dslrBooth | `check.bat` → `dslrbooth events`; Triggers URL в dslrBooth |
| Нет сообщений в Telegram | владелец не нажал Start; `TELEGRAM_ADMIN_CHAT_ID` должен быть числом |
| Логи | `logs/<BOOTH_ID>.log`, `logs/watchdog.log` |
