## 0. Что должно быть под рукой

- Ноутбук/ПК будки на Windows 10/11, камера + термопринтер подключены и работают в самом dslrBooth.
- Android-планшет + *Fully Kiosk Browser*.
- Свой роутер (4G или обычный) — **не гостевой Wi-Fi ТЦ**. ПК и планшет в одной сети.
- Готовый файл `.env` (прислан отдельно) на флешке.
- Аккаунт `@instaboxukraine` уже **нажал Start** у бота `t.me/InstaBOX_control_bot`.

## 1. Код на ПК будки

```
git clone https://github.com/httpsnek/photobooth_automation.git
cd photobooth_automation
```
Установлен ли Python 3.10+ — проверит следующий шаг.

## 2. Установка

Правой кнопкой на **`setup.bat`** → **Run as administrator**. Он:
- проверит Python и порт,
- создаст `.venv`, поставит зависимости (в т.ч. `pyautogui`, `psutil`),
- создаст `.env` (значения можно пропустить — заменим на готовый),
- зарегистрирует 2 задачи автозапуска: **`InstaBOX-<BOOTH_ID>`** и **`InstaBOX-watchdog-<BOOTH_ID>`**
  (AtLogOn, Run with highest privileges, авто-рестарт),
- **откроет порт 8000** в брандмауэре для локальной сети,
- **отключит сон / гибернацию / USB selective suspend / отключение монитора**.

**Затем:** скопировать готовый `.env` с флешки в корень проекта (заменить созданный).
В `.env` дозаполнить строки с `#!!! ЗАПОВНИТИ`:
- `BOOTH_ID`, `BOOTH_NAME` — id и название точки,
- `SUPPORT_TELEGRAM` — @username / t.me-ссылка поддержки (QR на экране ошибки); `SUPPORT_PHONE` если есть телефон,
- `PAPER_CAPACITY` — точное число отпечатков с рулона,
- `DSLRBOOTH_HOTKEY` — клавиша-триггер (см. шаг 3).

## 3. dslrBooth

1. Открыть dslrBooth, войти в аккаунт с активной подпиской (или триал для первого теста).
2. Настроить **Print**-сессию на 4 кадра. **Выключить** все экраны шеринга (email/SMS/QR) — иначе dslrBooth зависнет на них.
3. Назначить клавишу-триггер (Settings → Trigger / Remote) — например `F1`. Это же значение вписать в `.env` → `DSLRBOOTH_HOTKEY=F1`.
4. Поставить dslrBooth в автозапуск Windows и в полноэкранный режим.
5. *(с подпиской)* Settings → General → **Triggers** → URL:
   `http://localhost:8000/dslrbooth/event?token=_AE3vljmLHIgzCjmo0_E1c5H`
   и в `.env`: `DSLRBOOTH_TRIGGER=rest`, `DSLRBOOTH_EVENTS_ENABLED=1`, `DSLRBOOTH_API_PASSWORD=<пароль REST из dslrBooth>`.

## 4. Проверка перед запуском

```
check.bat
```
Всё должно быть `[  OK ]` или осознанный `[ WARN ]`. Ни одного `[ FAIL ]`.
Ожидаемо:
- `acquirer — Fotocab_maccoudi` — эквайринг отвечает,
- `telegram — @InstaBOX_control_bot`,
- `dslrbooth — hotkey 'F1' (pyautogui ok)`,
- `printer — <имя> status normal`.

## 5. Windows: автологин + питание (что setup.bat НЕ делает)

- Настроить **автоматический вход** в Windows для пользователя киоска
  (`netplwiz` → снять галку «Требовать ввод имени и пароля», ввести пароль).
  **Без этого автозапуск (`-AtLogOn`) не сработает.**
- Windows Update: задать **«период активности»** на круглые сутки или отложить
  перезагрузки — чтобы ПК не ушёл в ребут посреди работы.
- BIOS: **Restore on AC Power Loss = On** (если нет ИБП).
- Желательно небольшой **ИБП** на ПК + роутер.

*(Порт 8000 в брандмауэре и запрет сна/USB-suspend — уже сделал setup.bat.)*

## 6. Первый прогон (режим hotkey, деньги пока не трогаем)

1. Запустить: `schtasks /Run /TN InstaBOX-<id>`  (или просто `run.bat`).
2. На ПК открыть `http://localhost:8000/kiosk` — должен появиться экран с QR.
3. Тестовая оплата: пока `PAYMENT_PROVIDER=mock` — открыть pay-ссылку из `http://localhost:8000/status` … *(либо сразу перейти к п.7 с реальной 1 грн)*.
4. Убедиться: планшетный экран проходит `Дивіться в камеру → 3·2·1 → камера снимает 4 кадра → печать → Готово`.
5. Замерить секундомером время съёмки и печати → вписать в `.env`
   `SESSION_DURATION_SEC` / `PRINT_DURATION_SEC`, перезапустить задачу.

## 7. Боевой тест оплаты (1 грн)

1. В `.env`: `PRICE_UAH=1`, `PAYMENT_PROVIDER=monobank`. Перезапустить задачу.
2. Со своего телефона отсканировать QR, оплатить 1 грн реально.
3. Убедиться: пришло `💰 +1 UAH` в Telegram, кабинка отсняла и напечатала.
4. **Проверить возврат:** временно сломать триггер (закрыть dslrBooth) → оплатить ещё 1 грн → камера не сработает → через ~30 c должен прийти автовозврат + `⚠️` в Telegram. Проверить, что 1 грн вернулась на карту.
5. Вернуть `PRICE_UAH=150`, снова запустить dslrBooth. Перезапустить задачу.

## 8. Планшет (Fully Kiosk)

- URL: `http://<ip-ПК>:8000/kiosk`  (ip ПК закрепить статическим на роутере).
- Включить: *Start on Boot*, *Screen Always On*, *Auto Reload on Connection Error*,
  *Relaunch on Crash*. Отключить pull-to-refresh и адресную строку.
- Перезагрузить планшет → должен сам открыть киоск.

## 9. Финальная проверка «всё само поднимается»

1. Выдернуть питание ПК на 10 секунд, включить.
2. Windows зашёл сам → `run.bat` поднялся → dslrBooth запустился → планшет открыл киоск.
3. `check.bat` — снова всё зелёное.
4. Оставить на 10–15 минут, сделать 2–3 реальные съёмки. Проверить Telegram: оплаты, вечерняя сводка (в `DAILY_SUMMARY_HOUR`).

## Если что-то не так

| Симптом | Куда смотреть |
|---|---|
| Планшет: `Тимчасово не працює` | причина в Telegram; чаще всего — dslrBooth не запущен, нет бумаги, нет интернета |
| Нет сообщений в Telegram | владелец не нажал Start у бота; либо неверный `TELEGRAM_ADMIN_CHAT_ID` |
| `check.bat` → `acquirer` FAIL | неверный `BANK_TOKEN` или нет интернета |
| Камера не снимает по оплате | `DSLRBOOTH_HOTKEY` не совпадает с назначенной в dslrBooth; dslrBooth не в фокусе |
| Логи | `logs/<BOOTH_ID>.log`, `logs/watchdog.log` |
| Ручная пауза кабинки | `http://<ip>:8000/admin/pause?token=<ADMIN_TOKEN>` |
| После замены рулона | `http://<ip>:8000/admin/paper-reset?token=<ADMIN_TOKEN>` |

Обновление кода на точке: `update.bat` (git pull + зависимости) → перезапустить задачу.
